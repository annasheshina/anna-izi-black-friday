# ANNA IZI — Private Black Friday 2026

Одностраничный сайт на React, TypeScript и Vite.

## Предпросмотр

В папке проекта выполните `npm ci` и `npm run dev`. Откройте адрес из терминала. Добавьте `?preview=1` к адресу, чтобы проверить выбор продуктов вне дат кампании. Этот открытый параметр предназначен для локального просмотра.

## Публикация

Выполните `npm run build` и разместите содержимое папки `dist` на статическом хостинге.

- `src/campaign.ts` содержит даты, пути к изображениям, Telegram, ссылки оплаты и юридические ссылки. До заполнения ссылки скрыты. Посетитель может скопировать текст заявки.
- `src/content.json` содержит описания и цены. Нулевой остаток или выключенная доступность отключают выбор соответствующего лота. Подборка хранится в браузере.
- Кампания действует с 00:00 27 ноября до конца 29 ноября 2026 по Москве. В предварительном просмотре можно протестировать все кнопки.
- Для поэтапного открытия выставьте `openThrough` в `src/campaign.ts`: `1` открывает Discovery, `2` открывает Discovery и Expansion, `3` открывает все три уровня. Изменение появится на действующем сайте после публикации новой сборки.
- Сборка также создаёт две отдельные страницы `day-1.html` и `day-2.html` с фиксированными уровнями для первого и второго дня. Эти страницы доступны по прямым ссылкам и соблюдают общие даты кампании.
- Портрет, пейзажи и подпись взяты из приложенного макета. Обложки журналов — временные визуализации.
